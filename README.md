# ProjectFlow - Project Management Tool
## LEVEL 3 TASK 2

### Features
- Create and manage projects with color coding and priorities
- Kanban board with drag-style status management (To Do, In Progress, Review, Done)
- Task creation with assignees, due dates, tags, and priorities
- Task comments and collaboration
- Dashboard with charts and statistics
- My Tasks view with progress tracking and filtering
- User authentication (Register / Login)
- Responsive design

### Tech Stack
- **Frontend:** React 18, React Router, Recharts, React Hot Toast, React Icons
- **Backend:** Node.js, Express.js
- **Database:** MongoDB with Mongoose
- **Authentication:** JWT (JSON Web Tokens)
